# ⌚ Apple Watch to Windows PC Voice Controller

מערכת שליטה קולית בווליום של המחשב (Windows) דרך ה-Apple Watch, בעברית טבעית עם הבחנה מדויקת בין:
* **ערך יחסי ("ב-X אחוז"):** כגון *"תנמיך ב-50 אחוז"*, *"תגביר ב-20 אחוז"*.
* **ערך מוחלט ("ל-X אחוז"):** כגון *"תנמיך ל-50 אחוז"*, *"תגביר ל-80 אחוז"*, *"שים על 70"*.
* **השתקה וביטול השתקה:** כגון *"תשתיק"*, *"בטל השתקה"*.

---

## 🚀 איך להפעיל את השרת במחשב?

1. לחץ לחיצה כפולה על הקובץ:
   `d:\project\SpamOrNot\watch_pc_controller\start_server.bat`
2. השרת ייפתח בכתובת המקומית שלך:
   `http://localhost:8000` (או `http://192.168.68.59:8000`)
3. פתח את הדפדפן בכתובת [http://localhost:8000](http://localhost:8000) כדי לראות את **לוח הבקרה והטסטים בלייב**!

---

## 📱 בדיקה מיידית מה-Apple Watch (ללא התקנה - דרך קיצורי דרך)

אם אתה רוצה לבדוק את זה על השעון תוך 60 שניות:
1. פתח באייפון את אפליקציית **Shortcuts (קיצורי דרך)**.
2. לחץ על **+** ליצירת קיצור חדש וקרא לו: **"שלט ווליום"**.
3. הוסף פעולה 1: **"הכתב טקסט" (Dictate text)** - שפה: עברית.
4. הוסף פעולה 2: **"קבלת תוכן מכתובת URL" (Get contents of URL)**:
   * כתובת: `http://192.168.68.59:8000/api/command`
   * שיטה: **POST**
   * גוף הבקשה: **JSON**
   * מפתח: `text` -> ערך: **טקסט מוכתב**.
5. זהו! פתח את אפליקציית "קיצורי דרך" בשעון או אמור לסירי: *"היי סירי, שלט ווליום"*.

## ⌚ קוד האפליקציה המעוצבת (SwiftUI Watch App)
הקוד המלא עבור האפליקציה העצמאית נמצא בתיקייה:
`d:\project\SpamOrNot\watch_pc_controller\apple_watch_app/`
* `VoiceOrbVisualizer.swift` - כדור ה-Orb המונפש עם מצבי Idle, Listening, Thinking, Executing, Success.
* `ContentView.swift` - המסך הראשי עם פידבק צבעוני, רטט Haptic וכפתורי קיצור מהירים.
* `NetworkClient.swift` - מודול התקשורת מול ה-PC.
