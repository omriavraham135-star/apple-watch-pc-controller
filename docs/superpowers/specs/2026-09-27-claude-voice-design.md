# Claude בשעון: שיחה קולית עם Claude Code

**תאריך:** 2026-09-27
**סטטוס:** טיוטה לאישור

## המטרה

אותה חוויה כמו שיחה עם Claude Code בטרמינל: מדברים, Claude עונה, שואל, עובד על הפרויקט וממשיכים הלאה. ההבדלים: **מדברים** לשעון במקום להקליד, ו**שומעים** את התשובה במקום לקרוא טקסט ארוך על מסך קטן.

Claude בשעון הוא אותו Claude Code שבטרמינל. אותן שיחות, אותם כלים, אותם skills, אותו זיכרון ואותן הגדרות. אפשר להתחיל בשעון ולהמשיך במחשב, ולהפך.

## 1. החוויה

### 1.1 כניסה: דף "Claude"

דף חדש, **שני בסדר** (אחרי דף הקול), כי זה פיצ'ר מרכזי. במסך הראשון של הדף:

- **"המשך מאיפה שעצרנו"**: כפתור גדול עם שם הפרויקט, כותרת השיחה האחרונה ולפני כמה זמן
- **רשימת פרויקטים**: התיקיות ב‑`D:\Projects` וב‑`D:\project`, מסודרות לפי הפעילות האחרונה עם Claude. לכל פרויקט מוצגת כותרת השיחה האחרונה, ונקודת סטטוס אם Claude עובד שם או מחכה לך
- **"פרויקט חדש"**: אומרים שם, רואים אישור ("ליצור את D:\Projects\portfolio?"), מאשרים, ו‑Claude מתחיל
- **בחירה בקול**: "הפרויקט של הרובוט" או "רובוקס" מתאים ל‑`Robox`. ההתאמה בין עברית לשמות באנגלית נעשית במודל קטן ומהיר (Haiku), ותמיד מוצגת לאישור לפני שנכנסים

### 1.2 מסך השיחה

```
 ┌─────────────────────────┐
 │ 10:42        ● Robox     │  ← סטטוס + שם הפרויקט
 │                          │
 │        ( Orb )           │  ← מצב Claude, עשוי חלקיקים
 │   ✎ עורך server.py       │  ← מה הוא עושה עכשיו
 │                          │
 │  "הוספתי את הטיימר       │  ← התשובה, נגללת בכתר
 │   ובדקתי שהבדיקות עוברות"│
 │                          │
 │        [ 🎤 ]            │  ← לחיצה = דיבור
 └─────────────────────────┘
```

**מצבי ה‑Orb** (באותה שפת חלקיקים, בגוון חם של Claude שנבדל מה‑Orb הכחול של הווליום):

| מצב | מה רואים |
|---|---|
| מוכן | נשימה איטית |
| מקשיב | גלים שעוקבים אחרי עוצמת הקול האמיתית מהמיקרופון |
| חושב | סיבוב איטי |
| עובד | סמלים קטנים מקיפים את ה‑Orb לפי הכלי: ✎ עריכה, ⌘ פקודה, ⌕ חיפוש, ◎ קריאה |
| מדבר | החלקיקים פועמים עם עוצמת הקול של ההקראה |
| מחכה לך | פעימה ענברית עדינה (שאלה או בקשת אישור) |

### 1.3 לדבר

- **לחיצה על המיקרופון** מתחילה להקשיב. הטקסט מופיע **תוך כדי דיבור**
- **סיום אוטומטי** אחרי שנייה וחצי של שקט, או לחיצה נוספת
- **לפני שליחה**: הטקסט מוצג עם שלוש אפשרויות: **שלח** · **הוסף עוד** · **בטל**. במצב "ידיים חופשיות" נשלח אוטומטית אחרי שתי שניות
- **מצב ידיים חופשיות** (הגדרה): אחרי ש‑Claude מסיים לדבר, השעון מקשיב שוב לבד, כמו בשיחה
- **קטיעה**: לחיצה על ה‑Orb בזמן ש‑Claude מדבר עוצרת את ההקראה ומתחילה להקשיב. אם הוא באמצע עבודה, **"עצור"** בהחזקה של שנייה עוצר אותו, כמו Esc בטרמינל. אחר כך אפשר לתת כיוון חדש

### 1.4 לשמוע

- **ההקראה מתחילה אחרי המשפט הראשון**, לא אחרי שכל התשובה מוכנה
- **מה מוקרא:** רק החלק המדובר. קוד, טבלאות ורשימות קבצים ארוכות לא מוקראים. נתיב מוקרא כשם קובץ קצר ("server.py", לא "D:\project\...")
- **הטקסט נשאר על המסך** לגלילה בכתר. לכל תשובה יש שורת "מה נעשה", למשל "ערך 3 קבצים · הריץ בדיקות ✓", ולחיצה עליה מציגה את רשימת הקבצים
- **פקודות קוליות שמטופלות מקומית**, בלי לפנות ל‑Claude (מיידי ובלי עלות):
  - "עצור", "שקט": עוצר הקראה
  - "תחזור על זה": מקריא שוב
  - "יותר לאט" / "יותר מהר": מהירות הקראה
  - "מה אתה עושה?": מקריא את הסטטוס הנוכחי מתוך האירועים שכבר הגיעו

### 1.5 איך Claude מדבר כשהוא בשעון

לשיחות מהשעון מתווספת הנחיה (`--append-system-prompt`), בלי לשנות את Claude בטרמינל:

- לענות בעברית מדוברת, קצר, עד 3 משפטים
- בלי markdown, טבלאות או קוד בתשובה עצמה. קוד נכתב לקבצים, לא מוקרא
- לשאול שאלה אחת בכל פעם, עם אפשרויות קצרות (כמו כלי השאלות)
- כשיש פירוט ארוך, להגיד "פירטתי במחשב" ולהשאיר אותו בשיחה
- בסוף עבודה: משפט סיכום אחד של מה השתנה

כשממשיכים בשעון שיחה שהתחילה בטרמינל, ההנחיה חלה רק על התורות החדשות.

### 1.6 כש‑Claude שואל שאלה

כמו השאלות עם האפשרויות שאני שואל אותך:

- **כרטיס זכוכית** עולה מלמטה, עם כותרת קצרה, השאלה, ו‑2 עד 4 אפשרויות כגלולות גדולות
- **השעון מקריא** את השאלה ואת האפשרויות ("ראשונה: …, שנייה: …")
- **עונים** בלחיצה, בסיבוב הכתר ולחיצה, או **בקול** ("השנייה", או אומרים את שם האפשרות). ההתאמה לסדר או לשם נעשית מקומית
- **בחירה מרובה**: מסמנים כמה אפשרויות ולוחצים "שלח"
- **"משהו אחר"**: עונים בדיבור חופשי, והתשובה נשלחת כתשובה לשאלה

### 1.7 כש‑Claude צריך אישור (מצב "מאוזן")

- **אוטומטי, בלי לשאול:**
  - עריכה ויצירה של קבצים בתוך תיקיית הפרויקט (`acceptEdits`)
  - פקודות לקריאה בלבד, כמו `git status`, `git diff` או `ls`. הרשימה קבועה ואפשר לערוך אותה
  - **הרצת בדיקות לא נכללת כאן**, כי היא מריצה את הקוד של הפרויקט. היא תשאל בפעם הראשונה, ואחרי "אשר תמיד בפרויקט הזה" כבר לא
- **מחכה לאישור שלך:** כל פקודה אחרת. יופיע כרטיס עם:
  - סמל והסבר קצר בעברית (Claude מספק תיאור לכל פקודה)
  - **הפקודה המדויקת**, בגופן קבוע, נגללת
  - **רמת סיכון:**
    - רגילה: **החזקה של 2 שניות** לאישור
    - הרסנית (מחיקה, `git push`, `reset --hard`, רג'יסטרי, כיבוי): כרטיס אדום ו**החזקה של 3 שניות**
  - **"אשר תמיד בפרויקט הזה"**: נשמר ל‑`.claude/settings.local.json` של הפרויקט, בדיוק כמו "don't ask again" בטרמינל
  - **דחייה בלחיצה.** אפשר גם לדחות ולהגיד בקול למה ("לא, תעשה גיבוי קודם"), ו‑Claude מקבל את ההסבר
- **עבודה מחוץ לתיקיית הפרויקט תמיד מחכה לאישור**
- **אם אין תשובה:** הבקשה מחכה עד 30 דקות. אחר כך היא נדחית עם ההודעה "המשתמש לא זמין כרגע", ו‑Claude עוצר בצורה מסודרת

## 2. הארכיטקטורה

```
 שעון / דשבורד ──(HTTPS מקומי + טוקן)──► שרת Python במחשב
   דיבור→טקסט                              │
   נגן הקראה  ◄── SSE: אירועים + אודיו ────┤
                                            ├─ ClaudeSessionManager
                                            │    ClaudeSDKClient לכל שיחה פעילה
                                            │    cwd = תיקיית הפרויקט
                                            │    can_use_tool → גשר אישורים/שאלות
                                            ├─ TTS: edge-tts (Avri/Hila), גיבוי: Asaf
                                            └─ אינדקס שיחות: ~/.claude/projects/*
```

### 2.1 רכיבים בשרת (כל אחד במודול משלו)

| מודול | תפקיד |
|---|---|
| `claude_sessions.py` | ניהול שיחות פעילות: פתיחה, המשך, שליחת הודעה, עצירה, סגירה אחרי זמן סרק |
| `claude_bridge.py` | ה‑`can_use_tool`: הופך בקשות אישור ושאלות לאירועים לשעון ומחכה לתשובה |
| `claude_events.py` | מתרגם את זרם האירועים של Claude לאירועים פשוטים לשעון: `status`, `text`, `tool`, `question`, `approval`, `done`, `error` |
| `risk.py` | מסווג פקודות לפי רמת סיכון: קריאה בלבד / רגילה / הרסנית |
| `session_index.py` | קורא את היסטוריית השיחות של Claude Code: פרויקט, כותרת, זמן אחרון |
| `speech.py` | הקראה: מפצל משפטים, מסנן קוד ונתיבים, וממיר לאודיו |
| `pairing.py` | צימוד ואימות (ראו סעיף 3) |

### 2.2 ההחלטה הטכנית: Agent SDK או CLI

- **ברירת המחדל: `claude-agent-sdk` (Python).** יש לו `can_use_tool`, streaming input ועצירה, בצורה מסודרת ומתועדת
- **הצעד הראשון בתוכנית: בדיקה קצרה** שה‑SDK עובד עם החשבון שכבר מחובר ב‑Claude Code, בלי מפתח API
- **אם לא:** נשתמש ב‑CLI ישירות (`claude -p` עם stream-json בשני הכיוונים). אישורים יעברו דרך כלי MCP קטן שלנו (`--permission-prompt-tool`). זה עובד כבר עכשיו, כמו שבדקנו

### 2.3 חיי שיחה

- **תהליך פעיל אחד לכל שיחה פתוחה.** הודעות נוספות נכנסות לאותו תהליך, בלי לטעון מחדש את ההקשר, ולכן התגובה מהירה יותר
- **אחרי 15 דקות בלי פעילות** התהליך נסגר. השיחה נשמרת בדיסק, וההודעה הבאה ממשיכה אותה (`resume`)
- **כמה שיחות במקביל:** אפשר להשאיר את Claude לעבוד בפרויקט אחד ולעבור לאחר. ברשימה רואים מי "עובד" ומי "מחכה לך"
- **שיחה שפתוחה בטרמינל באותו רגע:** Claude Code פותח עותק ומודיע על כך. השעון מציג את ההודעה במפורש, כדי שלא יתבלבלו שתי שיחות
- **חיבור שנפל באמצע:** Claude ממשיך לעבוד במחשב. השרת שומר את האירועים האחרונים של כל שיחה, וכשהשעון חוזר הוא מתעדכן בכל מה שקרה

## 3. אבטחה: תנאי מוקדם לכל השאר

Claude Code יכול להריץ כל פקודה במחשב, וכרגע השרת פתוח לכל מכשיר ברשת הביתית. לכן:

1. **צימוד חד‑פעמי:**
   - השרת מציג במחשב קוד של 6 ספרות, ובשעון מזינים אותו פעם אחת
   - השעון מקבל טוקן ארוך ואקראי שנשמר אצלו. כל בקשה לשרת חייבת לכלול אותו
   - אפשר לבטל טוקן של מכשיר מהמחשב
2. **כל ה‑API דורש טוקן**, לא רק Claude, כי גם הכיבוי מסוכן
3. **Claude מוגבל לתיקיות הפרויקטים.** אין `--add-dir`, ו‑`bypassPermissions` לעולם לא בשימוש
4. **יומן ביקורת:** כל פקודה שאושרה או נדחתה נרשמת, ורואים את היומן בדשבורד
5. **הגבלת קצב** על ניסיונות צימוד

## 4. קול

### 4.1 דיבור לטקסט

- **בדשבורד:** Web Speech API בעברית (`he-IL`), עם תוצאות ביניים שמוצגות בזמן אמת. עובד ב‑Chrome, ב‑Edge וב‑Safari באייפון
- **באפליקציית השעון בעתיד:** ההכתבה של watchOS
- **מונחים טכניים:** "סרבר נקודה פיי" מגיע ל‑Claude כמו שהוא, והוא מבין. הטקסט מוצג לפני שליחה כדי שאפשר יהיה לתקן
- **שיפור אפשרי בגרסה עתידית:** Whisper מקומי במחשב, שמזהה טוב יותר עברית מעורבת באנגלית

### 4.2 טקסט לדיבור

- **ראשי:** `edge-tts` עם הקולות הנוירליים העבריים Avri (גבר) ו‑Hila (אישה). כבר מותקן, ודורש אינטרנט
- **גיבוי בלי אינטרנט:** Microsoft Asaf, מותקן במחשב
- **הזרמה משפט אחרי משפט:** המשפט הראשון מתחיל להתנגן בזמן שהבא עוד נכתב
- **הגדרות:** קול, מהירות, והקראה אוטומטית או רק בלחיצה

## 5. עיצוב (שפת "חלקיקים חיים")

- **ה‑Orb של Claude** הוא אותו כדור חלקיקים, בגוון טרקוטה עדין שמבדיל אותו מה‑Orb הכחול של הווליום
- **כשיש טקסט על המסך**, ה‑Orb מתכווץ ועולה למעלה, והטקסט תופס את מרכז המסך
- **כרטיסי שאלה ואישור** עולים מלמטה כזכוכית. האישור משתמש באותה החזקה עם מסגרת החלקיקים שנדלקת עם כיוון השעון, כמו בכיבוי ובמשחקים
- **רשימת השיחות:** מונוגרמה לכל פרויקט, כותרת, זמן, ונקודת סטטוס שנושמת כש‑Claude עובד
- **בלי זיקוקים ובלי קווים:** אותם כללים שקבענו

## 8. בדיקות

- **שרת:**
  - בדיקות יחידה עם "Claude מזויף" שמשמיע זרמי אירועים מוקלטים מהבדיקה האמיתית
  - הגשר: אישור, דחייה, "אשר תמיד", שאלה חד‑בחירה ורב‑בחירה, תשובה חופשית ופסק זמן
  - מסווג הסיכון: רשימת פקודות לכל רמה
  - הצימוד: בלי טוקן נחסם, טוקן שבוטל נחסם, הגבלת קצב
- **דשבורד:** בדיקות דפדפן (CDP) לדף Claude עם אירועים מדומים: מצבי ה‑Orb, כרטיס שאלה, החזקת אישור, קטיעה
- **ידני מקצה לקצה:** שיחה אמיתית אחת עם Claude, שכוללת שאלה, אישור פקודה והמשך בטרמינל

## 10. סדר העבודה המוצע

1. **אבטחה:** צימוד וטוקן לכל ה‑API
2. **בדיקת SDK:** האם הוא עובד עם החשבון המחובר (אם לא, CLI)
3. **שרת Claude:** שיחות, זרם אירועים, גשר אישורים ושאלות, מסווג סיכון, עם בדיקות
4. **הקראה:** `speech.py` ו‑edge-tts
5. **אב‑טיפוס עיצוב** לדף Claude בשפת החלקיקים
6. **חיבור לדשבורד האמיתי**, ביחד עם העברת העיצוב החדש של כל הדפים
7. **הפעלה אוטומטית של השרת** עם הכניסה ל‑Windows
