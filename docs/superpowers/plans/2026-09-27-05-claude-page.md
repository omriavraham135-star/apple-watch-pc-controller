# The Claude Page, Live — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Talking to Claude Code from the watch page: say something, see it before it goes, watch Claude work, hear the reply in the PC's voice, answer its questions and approve its commands with a hold, stop it, and move between projects and conversations — by touch or by voice.

**Architecture:** The Claude page of the new watch (plan 4) keeps its approved design; its scripted demo is replaced section by section with the live conversation. The decisions that are not drawing — reading the PC's event stream with `fetch` (so the token rides along) and resuming after a drop, the commands the watch handles itself, matching a spoken answer, summing up a turn, "switch to …" — live in a small UMD module, `static/watch/claude-logic.js`, tested in Node. The server gains one route, `POST /api/claude/match` (a small, fast model names the project the user meant), and opening a conversation now says where it stands (`last_seq`, `state`, `pending`).

**Tech Stack:** vanilla JS in the page, the Claude engine (plan 2), voice (plan 3), `claude-agent-sdk` `query()` with `claude-haiku-4-5` for the name match, Node 22 tests (`node --test`, CDP for the page).

**Spec:** `docs/superpowers/specs/2026-09-27-claude-voice-design.md` — sections 1.1–1.7, 5, 6, 7.

## Global Constraints

- **Nothing starts Claude Code until the Claude page is visited** (or a message is sent from the voice page). Loading the watch opens no conversation.
- One conversation at a time on the page. Opening says `{id, session_id, project, last_seq, state, pending}`; the page follows `/events?after=last_seq`, shows anything in `pending` at once, and on a drop reconnects after the last event it saw. A message that meets `404`/`503` reopens the same project once and is sent again.
- **Before it goes** (spec 1.3): the words appear as they are said; then a two-second line fills with `✕ בטל` and `＋ הוסף` (add more); a tap on the orb sends at once. The approved prototype sends after the countdown in every mode, not only hands-free — the later, approved design wins over the spec's first draft.
- **Speaking** (spec 1.4): each `say` event is spoken in order, never over another; the reply settles (caption + one-line summary) after its last sentence; `auto_read`, `hands_free` and `speed` come from `/api/voice/status` and `PUT /api/voice/settings`. A tap on the orb while Claude speaks mid-work only hushes it.
- **Handled on the watch** (spec 1.4): `עצור`/`שקט`, `תחזור על זה`, `יותר לאט`/`יותר מהר` (±0.1, 0.7–1.2, saved), `מה אתה עושה?` — never sent to Claude.
- **Questions** (spec 1.6): a card per question; tap, or `🎤` and say the option ("השנייה" or its words), or say something else (sent as `response`); `multi` questions toggle and send. **Approvals** (spec 1.7): the exact command, a hold of `hold_seconds` (2 normal, 3 destructive, red card), `תמיד בפרויקט הזה` only when `can_remember`, `דחה` → just no, or no with a spoken reason. One card at a time; an `answered` or `expired` event closes its card.
- **Stop**: holding the orb one second while Claude works sends `POST …/interrupt`; the interrupted turn ends with "עצרתי. מה לשנות?".
- **Projects** (spec 1.1): the six most recent from `/api/claude/projects` (monogram, colour, how long ago, "מחכה לך"), their last five conversations (the user's first words, else Claude's title), "שיחה חדשה", "פרויקט חדש" by voice (English folder name, confirmed; a taken name offers to continue there). "תעבור ל…" goes through `/api/claude/match` and is always confirmed; a name that matches nothing goes to Claude as it was said.
- **Waiting anywhere**: `/api/claude/conversations` every 4 s; a waiting project shows on every page's status bar ("Robox · Claude מחכה") and one tap goes there.
- Every text from Claude, the microphone or the PC enters the page as text (`esc()` / `textContent`), never as markup.
- The name-match model runs with no tools, its own temporary folder, and its session record deleted after the answer.
- Tests never reach the real Claude Code: the page gets a fake PC whose event stream the test writes into.

## Review Focus

1. **Claude asks two things at once** (two approvals, or a question and an approval) → one card at a time, each answer to its own request. Pinned in Task 6 (`two requests at once are asked one after the other`).
2. **The connection drops mid-turn** → the page resumes after the last event it saw and shows nothing twice. Pinned in Task 1 (`a dropped stream reconnects from the last event, and nothing is seen twice`) and Task 3 (`a dropped stream picks up after the last event it saw`).
3. **Claude's words, a folder name or a command contain markup** → shown as text, never run. Pinned in Task 3 (`markup in a reply is shown as text and never runs`), Task 4 (`a folder name with markup in it is shown as text`), Task 6 (`markup in a command is shown as text`).
4. **The PC closed the conversation after 15 quiet minutes** → the next message reopens it and still goes. Pinned in Task 3 (`a conversation the PC closed is opened again, and the message still goes`).
5. **"תעבור ל…" something that is not a project** ("תעבור לגרסה הקודמת") → it goes to Claude as it was said, not swallowed. Pinned in Task 7 (`"switch to" something that is not a project goes to Claude as it was said`).

```js
/**
 * The parts of the Claude page that are decisions rather than drawing:
 * spotting the commands the watch handles itself, matching a spoken answer
 * to an option, summing up what a turn did, and following the PC's event
 * stream (read with fetch, so the device's token can ride along, and
 * resumed from the last event after a drop).
 */
(function (root, factory) {
  const api = factory(root);
  if (typeof module === 'object' && module.exports) module.exports = api;
  else root.ClaudeLogic = api;
})(typeof self !== 'undefined' ? self : globalThis, function (root) {
  'use strict';

  const norm = (text) => String(text || '').replace(/[.,!?״"׳'׃]/g, ' ').replace(/\s+/g, ' ').trim();

  // ------------------------------------------------------------ handled on the watch (spec 1.4)

  const LOCAL = [
    { kind: 'stop', re: /^(עצור|תעצור|שקט|די|מספיק)$/ },
    { kind: 'repeat', re: /^(תחזור על זה|תחזור|שוב|עוד פעם)$/ },
    { kind: 'slower', re: /^(יותר לאט|לאט יותר|תאט)$/ },
    { kind: 'faster', re: /^(יותר מהר|מהר יותר|תאיץ)$/ },
    { kind: 'status', re: /^(מה אתה עושה|מה קורה|מה המצב)$/ },
  ];

  /** 'stop' | 'repeat' | 'slower' | 'faster' | 'status', or null when it is for Claude. */
  function localCommand(text) {
    const said = norm(text);
    const hit = LOCAL.find((c) => c.re.test(said));
    return hit ? hit.kind : null;
  }

  // ------------------------------------------------------------ answering a question by voice

  const ORDINALS = [
    ['ראשונה', 'הראשונה', 'ראשון', 'הראשון', 'אחת', 'אחד', '1'],
    ['שנייה', 'השנייה', 'שניה', 'השניה', 'שני', 'השני', 'שתיים', '2'],
    ['שלישית', 'השלישית', 'שלישי', 'השלישי', 'שלוש', '3'],
    ['רביעית', 'הרביעית', 'רביעי', 'הרביעי', 'ארבע', '4'],
  ];

  /** The option the user meant, by its place ("השנייה") or its words; -1 when none. */
  function matchOption(text, options) {
    const said = norm(text);
    if (!said) return -1;
    const words = said.split(' ');
    for (let i = 0; i < Math.min(options.length, ORDINALS.length); i++) {
      if (words.some((w) => ORDINALS[i].includes(w))) return i;
    }
    const low = said.toLowerCase();
    return options.findIndex((o) => {
      const label = norm(o.label).toLowerCase();
      return label && (low.includes(label) || label.includes(low));
    });
  }

  // ------------------------------------------------------------ tools and turns

  function toolKind(name) {
    if (/^(Edit|MultiEdit|Write|NotebookEdit)$/.test(name)) return 'edit';
    if (/^(Bash|PowerShell)$/.test(name)) return 'run';
    if (/^(Grep|Glob|WebSearch)$/.test(name)) return 'search';
    if (/^(Read|WebFetch|LS)$/.test(name)) return 'read';
    return 'think';
  }

  /** One line on what a turn did, e.g. "ערך 2 קבצים · הריץ פקודה ✓". tools: [{name, label, ok}]. */
  function turnSummary(tools) {
    const edited = new Set();
    let runs = 0, failed = 0;
    for (const t of tools) {
      const kind = toolKind(t.name);
      if (kind === 'edit') edited.add(t.label);
      if (kind === 'run') { runs++; if (t.ok === false) failed++; }
    }
    const parts = [];
    if (edited.size === 1) parts.push('ערך קובץ אחד');
    else if (edited.size > 1) parts.push(`ערך ${edited.size} קבצים`);
    if (runs === 1) parts.push(failed ? 'הריץ פקודה ✗' : 'הריץ פקודה ✓');
    else if (runs > 1) parts.push(`הריץ ${runs} פקודות · ` + (failed === 0 ? 'הכול עבר' : failed === 1 ? 'אחת נכשלה' : `${failed} נכשלו`));
    return parts.join(' · ');
  }

  // ------------------------------------------------------------ the event stream

  /** Feed it text as it arrives; it calls onEvent(event) for each complete server-sent event. */
  function SSEParser(onEvent) {
    let buf = '';
    return function feed(chunk) {
      buf += chunk;
      let at;
      while ((at = buf.indexOf('\n\n')) >= 0) {
        const block = buf.slice(0, at);
        buf = buf.slice(at + 2);
        let data = null;
        for (const line of block.split('\n')) {
          if (line.startsWith('data: ')) data = (data === null ? '' : data + '\n') + line.slice(6);
        }
        if (data === null) continue;                   // a keep-alive comment
        let event;
        try { event = JSON.parse(data); } catch (e) { continue; }
        onEvent(event);
      }
    };
  }

  /**
   * Follow a conversation's events from `after`, reconnecting from the last one
   * seen when the stream drops. opts: { fetch, token(), onEvent(e), onState(s), retryMs }.
   * States: 'open', 'retrying', 'unpaired', 'gone', 'closed'. Returns { close(), last }.
   */
  function openEvents(url, after, opts) {
    const doFetch = opts.fetch || ((...a) => root.fetch(...a));
    const retryMs = opts.retryMs === undefined ? 1000 : opts.retryMs;
    const state = (s) => { if (opts.onState) opts.onState(s); };
    let last = after, closed = false, controller = null;

    async function run() {
      while (!closed) {
        controller = new AbortController();
        try {
          const headers = {};
          const token = opts.token ? opts.token() : null;
          if (token) headers.Authorization = 'Bearer ' + token;
          const res = await doFetch(`${url}?after=${last}`, { headers, signal: controller.signal });
          if (res.status === 401 || res.status === 404) { state(res.status === 401 ? 'unpaired' : 'gone'); break; }
          if (!res.ok || !res.body) throw new Error(`stream ${res.status}`);
          state('open');
          const reader = res.body.getReader();
          const decoder = new TextDecoder();
          const feed = SSEParser((event) => {
            if (typeof event.seq === 'number' && event.seq <= last) return;
            if (typeof event.seq === 'number') last = event.seq;
            opts.onEvent(event);
          });
          for (;;) {
            const { value, done } = await reader.read();
            if (done) break;
            feed(decoder.decode(value, { stream: true }));
          }
        } catch (e) { /* dropped: try again below */ }
        if (closed) break;
        state('retrying');
        await new Promise((r) => setTimeout(r, retryMs));
      }
      state('closed');
    }
    run();
    return {
      close() { closed = true; if (controller) controller.abort(); },
      get last() { return last; },
    };
  }

  return { localCommand, matchOption, toolKind, turnSummary, SSEParser, openEvents };
});
```

```python
"""Which project did the user mean? "הפרויקט של הרובוט" or "רובוקס" → Robox.

A name said as it is written is matched here. Anything else goes to a small,
fast model (Haiku) with the list of folder names, and only an exact name from
that list counts. The watch always shows the match for confirmation before
anything opens (spec 1.1).
"""

import os
import re
import tempfile
from typing import Awaitable, Callable, Optional

MATCH_MODEL = "claude-haiku-4-5"
# The model's session record is kept out of the user's projects.
MATCH_DIR = os.path.join(tempfile.gettempdir(), "watch-pc-controller-match")


def _squash(text: str) -> str:
    return re.sub(r"[^a-z0-9]", "", text.lower())


def exact_match(said: str, names: list) -> Optional[str]:
    """A folder whose name appears in what was said, ignoring case, spaces and dashes."""
    words = _squash(said)
    if not words:
        return None
    hits = [n for n in names if _squash(n) and _squash(n) in words]
    return max(hits, key=len) if hits else None


def match_prompt(said: str, names: list) -> str:
    listing = "".join(f"- {n}\n" for n in names)
    return ("The user named one of their project folders out loud, in Hebrew: transliterated, "
            "translated or described.\n"
            f"They said: {said}\n"
            f"The folders are:\n{listing}"
            "Reply with exactly one folder name from the list, or NONE if none fits.")


async def _ask_haiku(prompt: str) -> str:
    from claude_agent_sdk import AssistantMessage, ClaudeAgentOptions, ResultMessage, TextBlock, delete_session, query

    os.makedirs(MATCH_DIR, exist_ok=True)
    options = ClaudeAgentOptions(
        model=MATCH_MODEL, max_turns=1, tools=[], setting_sources=[], cwd=MATCH_DIR,
        system_prompt="You match a spoken name to one folder name. Reply with the name only, or NONE.",
    )
    reply, session = [], None
    async for message in query(prompt=prompt, options=options):
        if isinstance(message, AssistantMessage):
            reply += [block.text for block in message.content if isinstance(block, TextBlock)]
        if isinstance(message, ResultMessage):
            session = message.session_id
    if session:
        try:
            delete_session(session, directory=MATCH_DIR)     # one-off lookups do not belong in the history
        except OSError:
            pass
    return "".join(reply)


async def match_project(said: str, names: list,
                        ask: Callable[[str], Awaitable[str]] = _ask_haiku) -> Optional[str]:
    if not said.strip() or not names:
        return None
    hit = exact_match(said, names)
    if hit:
        return hit
    answer = (await ask(match_prompt(said, names))).strip()
    return next((n for n in names if n.lower() == answer.lower()), None)
```

```js
  function ago(ms, now = Date.now()) {
    const s = Math.max(0, (now - ms) / 1000);
    const n = (v) => Math.round(v);
    if (s < 90) return 'עכשיו';
    if (s < 3600) return `לפני ${n(s / 60)} דק׳`;
```
