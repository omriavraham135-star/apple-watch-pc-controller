# Voice: ElevenLabs Both Ways, Fallbacks, HTTPS for the iPhone — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The server hears the user and speaks Claude's replies in Hebrew — ElevenLabs first, edge-tts and the offline Asaf voice as fallbacks — and serves the pages over HTTPS so an iPhone's Safari may use the microphone.

**Architecture:** The key and voice settings live only on the PC (`voice_config.py`). `speech_text.py` cuts Claude's streaming reply into spoken sentences (no code, tables or links; paths become file names) and the conversation publishes them as `say` events. `tts.py` speaks through ElevenLabs, then edge-tts, then Asaf, reporting which voice spoke and why. `listen.py` relays 16 kHz PCM from the browser to ElevenLabs Scribe v2 Realtime and returns partial and final text; the WebSocket authenticates itself because the HTTP middleware never sees WebSockets. `tls.py` makes a private CA and a server certificate; `run.py` serves http :8000 and https :8443 in one process. `static/voice.js` is the browser side the Claude page (plan 4) will use.

**Tech Stack:** Python 3.11 in the project `.venv` (FastAPI 0.141 / Starlette 1.7, uvicorn 0.54), httpx 0.28, `websockets==17.1`, `edge-tts==7.2.8`, `cryptography>=50` (50.0.1 installed), Windows WinRT speech via PowerShell, vanilla JS (AudioWorklet), Node 22 tests.

**Spec:** `docs/superpowers/specs/2026-09-27-claude-voice-design.md` — sections 1.3, 1.4, 4, 7 (voice rows), 3 (HTTPS on the LAN), 8 (voice tests).

## Global Constraints

- **The ElevenLabs key never leaves the PC:** read from `ELEVENLABS_API_KEY` or `watch_pc_controller/elevenlabs.key` (git-ignored); never sent to a browser, never logged, never printed, never typed into chat. The user enters it with `scripts/voice_setup.py` (hidden input).
- **TTS model:** the fastest of `eleven_v3_conversational`, `eleven_v3` that the account's `GET /v1/models` lists with Hebrew (docs conflict on whether the conversational model speaks Hebrew; setup asks the account). `eleven_multilingual_v2` / `eleven_flash_v2_5` do not speak Hebrew.
- **TTS request:** `POST /v1/text-to-speech/{voice_id}/stream?output_format=mp3_44100_128`, body `{"text", "model_id"}` plus `voice_settings.speed` only when not 1.0; speed range 0.7–1.2.
- **STT:** `wss://api.elevenlabs.io/v1/speech-to-text/realtime?model_id=scribe_v2_realtime&audio_format=pcm_16000&commit_strategy=vad&vad_silence_threshold_secs=1.5&language_code=he`, header `xi-api-key`; audio as `{"message_type": "input_audio_chunk", "audio_base_64", "commit", "sample_rate": 16000}`.
- **Fallbacks:** speech ElevenLabs → edge-tts `he-IL-AvriNeural` → Asaf (offline, WinRT); listening ElevenLabs → browser `SpeechRecognition` `he-IL`. A refused voice rests: quota 600 s, bad key 3600 s, busy/network 30 s.
- **Spoken text:** no code blocks, inline commands, tables or links; a path is read as its file name; a sentence ends at `. ! ? …` followed by white space, or a line break.
- **Listening ends** after 1.5 s of silence once speech was heard (spec 1.3), or after 8 s with nothing said.
- **HTTPS:** ECDSA P-256 / SHA-256; CA 10 years; server certificate 397 days with DNS + IP SANs and serverAuth EKU, renewed 30 days before the end or when the LAN address changes; keys in `watch_pc_controller/certs/` (git-ignored). Ports: http 8000, https 8443.
- **WebSocket security:** a browser `Origin` must equal `Host` (else close 1008); a non-local client must send `{"type": "auth", "token"}` first, within 5 s.
- **Open without a token:** `/cert` and everything under `/static/` (no secrets; a `<script>` tag cannot carry a token).
- Everything runs from `.venv\Scripts\python`; never install into the global Python.

```python
"""The voice settings, and the ElevenLabs key.

The key never leaves this PC: it is read from the ELEVENLABS_API_KEY
environment variable or from elevenlabs.key next to this file (git-ignored),
it is never sent to a browser, and it is never logged.
"""

import json
import os
from dataclasses import asdict, dataclass, fields
from typing import Optional

HERE = os.path.dirname(os.path.abspath(__file__))
KEY_FILE = os.path.join(HERE, "elevenlabs.key")
SETTINGS_FILE = os.path.join(HERE, "voice_settings.json")

# The only ElevenLabs models that speak Hebrew, fastest first. Setup asks the
# account's /v1/models which of them it really has.
TTS_MODELS = ("eleven_v3_conversational", "eleven_v3")
STT_MODEL = "scribe_v2_realtime"
SPEED_RANGE = (0.7, 1.2)


def elevenlabs_key(key_file: str = KEY_FILE) -> Optional[str]:
    key = os.environ.get("ELEVENLABS_API_KEY", "").strip()
    if key:
        return key
    try:
        with open(key_file, encoding="utf-8") as f:
            return f.readline().strip() or None
    except OSError:
        return None


@dataclass
class VoiceSettings:
    voice_id: Optional[str] = None      # an ElevenLabs voice; chosen by setup
    tts_model: str = "eleven_v3"        # setup replaces it with the fastest model that speaks Hebrew
    speed: float = 1.0                  # ElevenLabs' range: 0.7 to 1.2
    auto_read: bool = True              # read replies aloud without a tap
    hands_free: bool = False            # listen again after Claude finishes speaking


def load_settings(path: str = SETTINGS_FILE) -> VoiceSettings:
    try:
        with open(path, encoding="utf-8") as f:
            data = json.load(f)
    except (OSError, ValueError):
        return VoiceSettings()
    if not isinstance(data, dict):
        return VoiceSettings()
    known = {f.name for f in fields(VoiceSettings)}
    settings = VoiceSettings(**{k: v for k, v in data.items() if k in known})
    try:
        settings.speed = min(SPEED_RANGE[1], max(SPEED_RANGE[0], float(settings.speed)))
    except (TypeError, ValueError):
        settings.speed = 1.0
    return settings


def save_settings(settings: VoiceSettings, path: str = SETTINGS_FILE) -> None:
    tmp = path + ".tmp"
    with open(tmp, "w", encoding="utf-8") as f:
        json.dump(asdict(settings), f, ensure_ascii=False, indent=2)
    os.replace(tmp, path)


def _speaks_hebrew(model: dict) -> bool:
    return any(l.get("language_id") in ("he", "heb", "iw") or l.get("name") == "Hebrew"
               for l in (model.get("languages") or []))


def pick_hebrew_model(models: list) -> Optional[str]:
    """The fastest of TTS_MODELS that the account's /v1/models says speaks Hebrew."""
    speaks = {m.get("model_id") for m in models if isinstance(m, dict) and _speaks_hebrew(m)}
    return next((m for m in TTS_MODELS if m in speaks), None)
```

"""Set up ElevenLabs on this PC: the key, the Hebrew model and the voice.

Run it yourself, in a PowerShell window in the project folder:

    .venv\\Scripts\\python scripts\\voice_setup.py

The key is typed hidden, checked against ElevenLabs (reading the account
uses no credits), and saved only in watch_pc_controller\\elevenlabs.key,
which never goes to git. It is never printed.
"""

import getpass
import os
import sys

import httpx

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from watch_pc_controller.voice_config import (  # noqa: E402
    KEY_FILE,
    load_settings,
    pick_hebrew_model,
    save_settings,
)

API = "https://api.elevenlabs.io"


def main() -> int:
    key = getpass.getpass("ElevenLabs API key (typing is hidden): ").strip()
    if not key:
        print("No key entered. Nothing was saved.")
        return 1

    with httpx.Client(base_url=API, headers={"xi-api-key": key}, timeout=20) as http:
        sub = http.get("/v1/user/subscription")
        if sub.status_code == 401:
            print("ElevenLabs rejected this key (or it lacks the 'user read' permission). Nothing was saved.")
            return 1
        sub.raise_for_status()
        s = sub.json()

        models = http.get("/v1/models")
        models.raise_for_status()
        model = pick_hebrew_model(models.json())
        if not model:
            print("None of this account's models speaks Hebrew (expected eleven_v3). Nothing was saved.")
            return 1

        voices = http.get("/v2/voices", params={"page_size": 30})
        voices.raise_for_status()
        listed = voices.json().get("voices", [])

    if not listed:
        print("The account has no voices. Add one at elevenlabs.io and run this again.")
        return 1
    print(f"\nCharacters this month: {s.get('character_count')}/{s.get('character_limit')}")
    print(f"Hebrew model: {model}\n")
    for i, v in enumerate(listed, 1):
        print(f"{i:2}. {v.get('name')}  ({v.get('category', '')})")
    choice = input(f"\nWhich voice? [1-{len(listed)}, Enter = 1]: ").strip() or "1"
    try:
        voice = listed[int(choice) - 1]
    except (ValueError, IndexError):
        print("Not a number from the list. Nothing was saved.")
        return 1

    with open(KEY_FILE, "w", encoding="utf-8") as f:
        f.write(key + "\n")
    settings = load_settings()
    settings.voice_id = voice["voice_id"]
    settings.tts_model = model
    save_settings(settings)
    print(f"\nSaved. Voice: {voice.get('name')}. Restart the server to use it.")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

`watch_pc_controller/speech_text.py`:

```python
"""What of Claude's reply is read aloud, one sentence at a time.

The watch reads only the spoken part: code blocks, tables and links stay on
the screen, and a path is read as its file name. Text arrives in small
pieces while Claude writes, so a sentence is handed on as soon as it ends,
and the first one can be spoken before the reply is finished.
"""

import re

_FENCE = "```"
# A sentence ends at . ! ? … followed by white space, or at a line break,
# so "server.py" and "3.5" stay whole.
_END = re.compile(r"[.!?…]+(?=\s)|\n")
_LINK = re.compile(r"\[([^\]]+)\]\([^)]*\)")
_URL = re.compile(r"https?://\S+?(?=[.,!?…]?(?:\s|$))")
_INLINE_CODE = re.compile(r"`([^`]*)`")
# a run of path parts: at least one separator, optionally rooted. Parts are
# ASCII, so a Hebrew prefix ("ב-") stays outside and "ו/או" is not a path.
_PATH = re.compile(r"(?<![\w\\/])(?:[A-Za-z]:)?[\\/]?(?:[A-Za-z0-9_.\-~]+[\\/])+[A-Za-z0-9_.\-]*[A-Za-z0-9_]")
_LEAD = re.compile(r"^(?:#{1,6}\s+|>\s*|[-*+•]\s+|\d+[.)]\s+)")
_EMPHASIS = re.compile(r"(\*\*|__|\*)(.+?)\1")
_RULE = set("-=*_|: ")


def _last_part(path: str) -> str:
    return re.split(r"[\\/]", path.rstrip("\\/"))[-1]


def _looks_like_a_path(path: str) -> bool:
    rooted = bool(re.match(r"(?:[A-Za-z]:)?[\\/]|~", path))
    has_extension = bool(re.search(r"\.\w{1,5}$", path))
    return rooted or has_extension


def _path(match: re.Match) -> str:
    text = match.group(0)
    return _last_part(text) if _looks_like_a_path(text) else text


def _inline_code(match: re.Match) -> str:
    code = match.group(1).strip()
    if not code or " " in code or "=" in code:        # a command or an expression: not read
        return ""
    return _last_part(code)


def spoken_sentence(text: str) -> str:
    """One sentence or line, as it should sound. Empty when there is nothing to say."""
    line = text.strip()
    if not line or line.startswith("|") or set(line) <= _RULE or line.startswith(_FENCE):
        return ""
    line = _LEAD.sub("", line)
    line = _LINK.sub(r"\1", line)
    line = _INLINE_CODE.sub(_inline_code, line)
    line = _URL.sub("קישור", line)
    line = _PATH.sub(_path, line)
    line = _EMPHASIS.sub(r"\2", line)
    line = re.sub(r"\s+", " ", line).strip()
    line = re.sub(r"\s+([.,!?…:])", r"\1", line)
    return line if re.search(r"\w", line) else ""


def _cut(text: str) -> tuple:
    """Complete sentences in `text`, and the unfinished rest."""
    sentences, start = [], 0
    for match in _END.finditer(text):
        said = spoken_sentence(text[start:match.end()])
        if said:
            sentences.append(said)
        start = match.end()
    return sentences, text[start:]


class SpokenStream:
    """Feed Claude's text as it arrives; get back sentences ready to speak."""

    def __init__(self):
        self._buf = ""
        self._in_code = False

    def feed(self, text: str) -> list:
        self._buf += text
        out = []
        while True:
            if self._in_code:
                end = self._buf.find(_FENCE)
                if end < 0:
                    # keep a possible half-arrived closing fence
                    self._buf = self._buf[-2:] if self._buf.endswith("`") else ""
                    return out
                self._buf = self._buf[end + len(_FENCE):]
                self._in_code = False
                continue
            start = self._buf.find(_FENCE)
            if start < 0:
                sentences, self._buf = _cut(self._buf)
                return out + sentences
            sentences, rest = _cut(self._buf[:start])
            out += sentences
            said = spoken_sentence(rest)            # what came before a code block is a whole thought
            if said:
                out.append(said)
            self._buf = self._buf[start + len(_FENCE):]
            self._in_code = True

    def flush(self) -> list:
        """The end of the text: whatever is left, and a fresh start."""
        rest = "" if self._in_code else self._buf
        self._buf, self._in_code = "", False
        sentences, tail = _cut(rest)
        said = spoken_sentence(tail)
        return sentences + ([said] if said else [])


def spoken(text: str) -> list:
    stream = SpokenStream()
    return stream.feed(text) + stream.flush()
```

"""Turning text into Hebrew speech, with a fallback when ElevenLabs cannot.

ElevenLabs speaks first. When it refuses (no key, a bad key, the quota is
used up, too busy, no network) the next voice takes over: edge-tts online,
then the offline Microsoft Asaf voice. The caller learns which voice spoke
and why, and a refused voice rests for a while instead of being asked again
for every sentence.
"""

import asyncio
import base64
import os
import subprocess
import tempfile
import time
from dataclasses import dataclass
from typing import AsyncIterator, Callable, Optional

import httpx

from watch_pc_controller.voice_config import VoiceSettings

ELEVENLABS_API = "https://api.elevenlabs.io"
ASAF_SCRIPT = os.path.join(os.path.dirname(os.path.abspath(__file__)), "asaf.ps1")

# (reason, seconds before trying that voice again)
_REFUSALS = {
    "invalid_api_key": ("invalid_key", 3600),
    "quota_exceeded": ("quota", 600),
    "too_many_concurrent_requests": ("busy", 30),
    "system_busy": ("busy", 30),
}


class VoiceUnavailable(Exception):
    def __init__(self, reason: str, retry_after_s: float = 0):
        super().__init__(reason)
        self.reason = reason
        self.retry_after_s = retry_after_s


@dataclass
class Speech:
    provider: str
    media_type: str
    chunks: AsyncIterator[bytes]
    fallback_reason: str = ""


def _refusal(status: int, body: bytes) -> VoiceUnavailable:
    try:
        import json
        detail = json.loads(body).get("detail")
        code = detail.get("status") if isinstance(detail, dict) else None
    except (ValueError, AttributeError):
        code = None
    if code in _REFUSALS:
        return VoiceUnavailable(*_REFUSALS[code])
    if status == 401:
        return VoiceUnavailable("invalid_key", 3600)
    if status == 429:
        return VoiceUnavailable("busy", 30)
    return VoiceUnavailable(f"error_{status}", 30)


class ElevenLabsTTS:
    name = "elevenlabs"
    media_type = "audio/mpeg"

    def __init__(self, api_key: Optional[str], voice_id: Optional[str], model_id: str,
                 transport: Optional[httpx.AsyncBaseTransport] = None):
        self._key, self._voice, self._model, self._transport = api_key, voice_id, model_id, transport

    async def open(self, text: str, speed: float) -> AsyncIterator[bytes]:
        if not self._key:
            raise VoiceUnavailable("no_key")
        if not self._voice:
            raise VoiceUnavailable("no_voice")
        body = {"text": text, "model_id": self._model}
        if abs(speed - 1.0) > 1e-6:
            body["voice_settings"] = {"speed": speed}
        client = httpx.AsyncClient(base_url=ELEVENLABS_API, transport=self._transport,
                                   timeout=httpx.Timeout(20.0, read=60.0))
        request = client.build_request("POST", f"/v1/text-to-speech/{self._voice}/stream",
                                       params={"output_format": "mp3_44100_128"},
                                       headers={"xi-api-key": self._key}, json=body)
        try:
            response = await client.send(request, stream=True)
        except httpx.HTTPError as exc:
            await client.aclose()
            raise VoiceUnavailable("network", 30) from exc
        if response.status_code != 200:
            refusal = _refusal(response.status_code, await response.aread())
            await response.aclose()
            await client.aclose()
            raise refusal

        async def chunks():
            try:
                async for chunk in response.aiter_bytes():
                    yield chunk
            finally:
                await response.aclose()
                await client.aclose()
        return chunks()


class EdgeTTS:
    name = "edge"
    media_type = "audio/mpeg"

    def __init__(self, voice: str = "he-IL-AvriNeural", communicate: Optional[Callable] = None):
        if communicate is None:
            import edge_tts
            communicate = edge_tts.Communicate
        self._voice, self._communicate = voice, communicate

    async def open(self, text: str, speed: float) -> AsyncIterator[bytes]:
        rate = f"{round((speed - 1.0) * 100):+d}%"
        stream = self._communicate(text, self._voice, rate=rate).stream()
        try:
            first = None
            async for chunk in stream:            # wait for real audio, so a failure shows now
                if chunk.get("type") == "audio":
                    first = chunk["data"]
                    break
        except Exception as exc:                  # edge-tts raises aiohttp and its own errors
            raise VoiceUnavailable("offline", 30) from exc
        if first is None:
            raise VoiceUnavailable("offline", 30)

        async def chunks():
            yield first
            async for chunk in stream:
                if chunk.get("type") == "audio":
                    yield chunk["data"]
        return chunks()


async def _run_hidden(args: list) -> int:
    process = await asyncio.create_subprocess_exec(
        *args, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
        creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0))
    try:
        return await asyncio.wait_for(process.wait(), 30)
    except asyncio.TimeoutError:
        process.kill()
        return -1


class AsafTTS:
    """The offline Hebrew voice. It is a OneCore voice, reachable only through WinRT (asaf.ps1)."""

    name = "asaf"
    media_type = "audio/wav"

    def __init__(self, run: Callable = _run_hidden):
        self._run = run

    async def open(self, text: str, speed: float) -> AsyncIterator[bytes]:
        encoded = base64.b64encode(text.encode("utf-8")).decode("ascii")   # Hebrew survives the command line
        with tempfile.TemporaryDirectory() as folder:
            out = os.path.join(folder, "speech.wav")
            code = await self._run(["powershell.exe", "-NoProfile", "-STA", "-ExecutionPolicy", "Bypass",
                                    "-File", ASAF_SCRIPT, "-TextBase64", encoded, "-OutFile", out,
                                    "-Rate", f"{speed:.2f}"])
            if code != 0 or not os.path.exists(out):
                raise VoiceUnavailable("offline_voice_failed", 300)
            with open(out, "rb") as f:
                audio = f.read()

        async def chunks():
            yield audio
        return chunks()


class Speaker:
    def __init__(self, voices: list, clock: Callable[[], float] = time.monotonic):
        self.voices = voices
        self._clock = clock
        self._resting_until: dict = {}
        self._reasons: dict = {}

    async def speak(self, text: str, speed: float = 1.0) -> Speech:
        reasons = []
        for voice in self.voices:
            if self._clock() < self._resting_until.get(voice.name, 0):
                reasons.append(self._reasons[voice.name])
                continue
            try:
                chunks = await voice.open(text, speed)
            except VoiceUnavailable as exc:
                self._resting_until[voice.name] = self._clock() + exc.retry_after_s
                self._reasons[voice.name] = exc.reason
                reasons.append(exc.reason)
                continue
            self._reasons[voice.name] = ""
            return Speech(voice.name, voice.media_type, chunks, fallback_reason=reasons[0] if reasons else "")
        raise VoiceUnavailable("no_voice_available")

    def status(self) -> dict:
        now = self._clock()
        return {v.name: {"available": now >= self._resting_until.get(v.name, 0), "reason": self._reasons.get(v.name, "")}
                for v in self.voices}


def build_speaker(settings: VoiceSettings, key: Optional[str]) -> Speaker:
    return Speaker([ElevenLabsTTS(key, settings.voice_id, settings.tts_model), EdgeTTS(), AsafTTS()])

        return self

        if item is None:

        return item

        self.closed = True
        self._inbox.put_nowait(None)

"""Hearing the user: the browser's microphone, relayed to ElevenLabs Scribe.

The browser sends 16 kHz 16-bit mono PCM over a WebSocket to this server;
each piece is wrapped for Scribe v2 Realtime and what it hears comes back:
partial text while the user talks, a committed piece after each pause.
When the user stops, one last commit flushes the rest. The key stays here:
the browser only ever talks to this server.

Message formats follow the official ElevenLabs SDK (elevenlabs 2.69.0,
realtime/connection.py and realtime/scribe.py).
"""

import asyncio
import base64
import json
from typing import Awaitable, Callable, Optional
from urllib.parse import urlencode

from watch_pc_controller.voice_config import STT_MODEL

SCRIBE_URL = "wss://api.elevenlabs.io/v1/speech-to-text/realtime"
SAMPLE_RATE = 16000
SILENCE_S = 1.5          # spec 1.3: listening ends after a second and a half of silence

_ERRORS = {
    "auth_error": "invalid_key",
    "quota_exceeded": "quota",
    "rate_limited": "busy",
    "resource_exhausted": "busy",
    "queue_overflow": "busy",
    "commit_throttled": "busy",
    "session_time_limit_exceeded": "too_long",
    "unaccepted_terms": "terms",
    "unaccepted_terms_error": "terms",
    "transcriber_error": "transcriber_error",
    "input_error": "input_error",
    "invalid_request": "invalid_request",
    "chunk_size_exceeded": "input_error",
    "insufficient_audio_activity": "no_speech",
    "error": "error",
}


def scribe_url(language: str = "he", silence_s: float = SILENCE_S) -> str:
    return SCRIBE_URL + "?" + urlencode([
        ("model_id", STT_MODEL),
        ("audio_format", "pcm_16000"),
        ("commit_strategy", "vad"),
        ("vad_silence_threshold_secs", str(silence_s)),
        ("language_code", language),
    ])


def audio_message(pcm: bytes, commit: bool = False) -> str:
    return json.dumps({
        "message_type": "input_audio_chunk",
        "audio_base_64": base64.b64encode(pcm).decode("ascii"),
        "commit": commit,
        "sample_rate": SAMPLE_RATE,
    })


def translate_scribe(message: dict) -> Optional[dict]:
    kind = message.get("message_type")
    if kind == "partial_transcript":
        return {"type": "partial", "text": message.get("text", "")}
    if kind == "committed_transcript":
        return {"type": "final", "text": message.get("text", "")}
    if kind in _ERRORS:
        return {"type": "error", "reason": _ERRORS[kind]}
    return None                       # session_started, timestamps, entities


async def relay(receive: Callable[[], Awaitable[tuple]], send: Callable[[dict], Awaitable[None]],
                upstream, final_wait_s: float = 3.0, quiet_s: float = 0.5) -> str:
    """Pump audio up and events down until the user stops or leaves.

    `receive()` returns ("audio", bytes), ("stop", None) or ("closed", None).
    After a stop, the last pieces are collected until Scribe has been quiet
    for `quiet_s` after a final, or `final_wait_s` passes. Returns the whole
    transcript. Scribe is always closed on the way out.
    """
    loop = asyncio.get_running_loop()
    finals: list[str] = []
    last_final_at = [None]
    finished = asyncio.Event()        # Scribe ended the session (or failed)

    async def down():
        try:
            async for raw in upstream:
                try:
                    event = translate_scribe(json.loads(raw))
                except ValueError:
                    continue
                if event is None:
                    continue
                await send(event)
                if event["type"] == "error":
                    break
                if event["type"] == "final":
                    if event["text"]:
                        finals.append(event["text"])
                    last_final_at[0] = loop.time()
        finally:
            finished.set()

    async def settle_after_stop(stop_at: float) -> None:
        while not finished.is_set():
            now = loop.time()
            heard = last_final_at[0]
            if now - stop_at >= final_wait_s or (heard is not None and heard >= stop_at and now - heard >= quiet_s):
                return
            await asyncio.sleep(0.05)

    async def up():
        while True:
            kind, data = await receive()
            if kind == "audio":
                await upstream.send(audio_message(data))
            elif kind == "stop":
                await upstream.send(audio_message(b"", commit=True))
                return "stopped"
            else:
                return "closed"

    reader = asyncio.create_task(down())
    writer = asyncio.create_task(up())
    try:
        await asyncio.wait({reader, writer}, return_when=asyncio.FIRST_COMPLETED)
        if writer.done() and not writer.cancelled() and writer.exception() is None and writer.result() == "stopped":
            await settle_after_stop(loop.time())
            text = " ".join(finals)
            await send({"type": "done", "text": text})
            return text
        if reader.done() and not writer.done():
            return " ".join(finals)          # Scribe ended it (an error was already passed on)
        return ""                            # the browser left
    finally:
        for task in (reader, writer):
            task.cancel()
        await upstream.close()


async def connect_scribe(api_key: str, language: str = "he"):
    """Open the upstream connection. Raises VoiceUnavailable with a reason on refusal."""
    from websockets.asyncio.client import connect
    from websockets.exceptions import InvalidStatus

    from watch_pc_controller.tts import VoiceUnavailable

    try:
        return await connect(scribe_url(language), additional_headers={"xi-api-key": api_key}, open_timeout=10)
    except InvalidStatus as exc:
        status = exc.response.status_code
        raise VoiceUnavailable("invalid_key" if status in (401, 403) else "busy" if status == 429 else f"error_{status}") from exc
    except OSError as exc:
        raise VoiceUnavailable("network") from exc

The ElevenLabs key never leaves this module's process: the browser asks this
server to speak or to listen, and the server talks to ElevenLabs.

def _same_origin(ws: WebSocket) -> bool:
    """A browser always sends Origin; a page from another site must not open this socket."""
    origin = ws.headers.get("origin")
    if origin is None:
        return True                    # not a browser (the watch app)
    try:
        return urlsplit(origin).netloc.lower() == ws.headers.get("host", "").lower()
    except ValueError:
        return False


def _token_ok(token) -> bool:
    from watch_pc_controller import server      # late: server imports this module
    return isinstance(token, str) and server.pairing_store.verify(token) is not None


@router.websocket("/listen")
async def listen(ws: WebSocket):
    # The HTTP auth middleware never sees WebSockets, so this socket checks for itself.
    if not _same_origin(ws):
        await ws.close(code=1008)
        return
    await ws.accept()
    if not request_is_local(ws):
        # Browsers cannot put headers on a WebSocket, so the token comes as the first message.
        try:
            first = await asyncio.wait_for(ws.receive_json(), AUTH_WAIT_S)
        except (asyncio.TimeoutError, WebSocketDisconnect, ValueError, KeyError):
            await ws.close(code=1008)
            return
        if not isinstance(first, dict) or first.get("type") != "auth" or not _token_ok(first.get("token")):
            await ws.close(code=1008)
            return

    key = elevenlabs_key()
    if not key:
        await ws.send_json({"type": "unavailable", "reason": "no_key"})
        await ws.close()
        return
    try:
        upstream = await connect_scribe(key)
    except VoiceUnavailable as exc:
        await ws.send_json({"type": "unavailable", "reason": exc.reason})
        await ws.close()
        return
    await ws.send_json({"type": "ready"})

    async def receive():
        while True:
            message = await ws.receive()
            if message["type"] == "websocket.disconnect":
                return ("closed", None)
            if message.get("bytes") is not None:
                return ("audio", message["bytes"])
            try:
                data = json.loads(message.get("text") or "{}")
            except ValueError:
                continue
            if isinstance(data, dict) and data.get("type") == "stop":
                return ("stop", None)
            # anything else (such as a local page's auth message) is ignored

    async def send(event: dict) -> None:
        try:
            await ws.send_json(event)
        except (WebSocketDisconnect, RuntimeError):
            pass

    await relay(receive, send, upstream)
    try:
        await ws.close()
    except RuntimeError:
        pass

```python
"""A private certificate authority, so an iPhone on the home Wi-Fi can use HTTPS.

Browsers give the microphone only to secure pages. This makes a CA once (ten
years) and, from it, a server certificate for this PC's names and addresses:
397 days, renewed a month before it ends, and remade when the PC's address
changes. The iPhone trusts the CA once; after that everything just works.
The private keys stay in certs/, which never goes to git.

Apple's rules (support.apple.com/103769): SAN names, serverAuth EKU, SHA-256,
at most 825 days; we use 397 to stay inside the stricter public-CA limit too.
"""

import datetime
import ipaddress
import os
import socket
from typing import Optional

from cryptography import x509
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.x509.oid import ExtendedKeyUsageOID, NameOID

CERT_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "certs")
CA_DAYS = 3650
LEAF_DAYS = 397
RENEW_BEFORE_DAYS = 30


def local_names() -> tuple:
    """(DNS names, IP addresses) this PC answers to on the home network."""
    host = socket.gethostname()
    ips = {"127.0.0.1"}
    try:
        for info in socket.getaddrinfo(host, None, socket.AF_INET):
            ips.add(info[4][0])
    except OSError:
        pass
    try:                                           # the address used to reach the router
        with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as s:
            s.connect(("10.255.255.255", 1))
            ips.add(s.getsockname()[0])
    except OSError:
        pass
    ips = {ip for ip in ips if not ip.startswith("169.254.")}
    return ["localhost", host, f"{host}.local"], sorted(ips)


def _write(path: str, data: bytes) -> None:
    with open(path, "wb") as f:
        f.write(data)


def _load_cert(path: str) -> Optional[x509.Certificate]:
    try:
        with open(path, "rb") as f:
            return x509.load_pem_x509_certificate(f.read())
    except (OSError, ValueError):
        return None


def _load_key(path: str):
    try:
        with open(path, "rb") as f:
            return serialization.load_pem_private_key(f.read(), password=None)
    except (OSError, ValueError):
        return None


def _pem_key(key) -> bytes:
    return key.private_bytes(serialization.Encoding.PEM, serialization.PrivateFormat.PKCS8, serialization.NoEncryption())


def _make_ca(now: datetime.datetime):
    key = ec.generate_private_key(ec.SECP256R1())
    name = x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, "Apple Watch PC Controller (this PC only)")])
    cert = (x509.CertificateBuilder()
            .subject_name(name).issuer_name(name)
            .public_key(key.public_key())
            .serial_number(x509.random_serial_number())
            .not_valid_before(now - datetime.timedelta(minutes=5))
            .not_valid_after(now + datetime.timedelta(days=CA_DAYS))
            .add_extension(x509.BasicConstraints(ca=True, path_length=0), critical=True)
            .add_extension(x509.KeyUsage(digital_signature=True, key_cert_sign=True, crl_sign=True,
                                         content_commitment=False, key_encipherment=False, data_encipherment=False,
                                         key_agreement=False, encipher_only=False, decipher_only=False), critical=True)
            .add_extension(x509.SubjectKeyIdentifier.from_public_key(key.public_key()), critical=False)
            .sign(key, hashes.SHA256()))
    return key, cert


def _make_leaf(ca_key, ca_cert, dns: list, ips: list, now: datetime.datetime):
    key = ec.generate_private_key(ec.SECP256R1())
    names = [x509.DNSName(d) for d in dns] + [x509.IPAddress(ipaddress.ip_address(ip)) for ip in ips]
    cert = (x509.CertificateBuilder()
            .subject_name(x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, dns[0])]))
            .issuer_name(ca_cert.subject)
            .public_key(key.public_key())
            .serial_number(x509.random_serial_number())
            .not_valid_before(now - datetime.timedelta(minutes=5))
            .not_valid_after(now + datetime.timedelta(days=LEAF_DAYS))
            .add_extension(x509.SubjectAlternativeName(names), critical=False)
            .add_extension(x509.BasicConstraints(ca=False, path_length=None), critical=True)
            .add_extension(x509.ExtendedKeyUsage([ExtendedKeyUsageOID.SERVER_AUTH]), critical=False)
            .add_extension(x509.AuthorityKeyIdentifier.from_issuer_public_key(ca_key.public_key()), critical=False)
            .sign(ca_key, hashes.SHA256()))
    return key, cert


def _leaf_fits(leaf, ca_cert, dns: list, ips: list, now: datetime.datetime) -> bool:
    if leaf is None or leaf.issuer != ca_cert.subject:
        return False
    if leaf.not_valid_after_utc - now < datetime.timedelta(days=RENEW_BEFORE_DAYS):
        return False
    san = leaf.extensions.get_extension_for_class(x509.SubjectAlternativeName).value
    have_ips = sorted(str(ip) for ip in san.get_values_for_type(x509.IPAddress))
    return sorted(san.get_values_for_type(x509.DNSName)) == sorted(dns) and have_ips == sorted(ips)


def ensure_certificates(cert_dir: Optional[str] = None, dns: Optional[list] = None, ips: Optional[list] = None,
                        now: Optional[datetime.datetime] = None) -> tuple:
    """Make or refresh the certificates; returns (server certificate path, server key path)."""
    cert_dir = cert_dir or CERT_DIR
    if dns is None or ips is None:
        found_dns, found_ips = local_names()
        dns, ips = dns or found_dns, ips or found_ips
    now = now or datetime.datetime.now(datetime.timezone.utc)
    os.makedirs(cert_dir, exist_ok=True)
    ca_pem, ca_key_path = os.path.join(cert_dir, "ca.pem"), os.path.join(cert_dir, "ca.key")
    leaf_pem, leaf_key_path = os.path.join(cert_dir, "server.pem"), os.path.join(cert_dir, "server.key")

    ca_cert, ca_key = _load_cert(ca_pem), _load_key(ca_key_path)
    if ca_cert is None or ca_key is None or ca_cert.not_valid_after_utc <= now:
        ca_key, ca_cert = _make_ca(now)
        _write(ca_key_path, _pem_key(ca_key))
        _write(ca_pem, ca_cert.public_bytes(serialization.Encoding.PEM))

    if not _leaf_fits(_load_cert(leaf_pem), ca_cert, dns, ips, now) or _load_key(leaf_key_path) is None:
        key, cert = _make_leaf(ca_key, ca_cert, dns, ips, now)
        _write(leaf_key_path, _pem_key(key))
        _write(leaf_pem, cert.public_bytes(serialization.Encoding.PEM))
    return leaf_pem, leaf_key_path


def ca_der(cert_dir: Optional[str] = None) -> bytes:
    """The CA certificate as an iPhone installs it (DER, .cer)."""
    cert_dir = cert_dir or CERT_DIR
    path = os.path.join(cert_dir, "ca.pem")
    if _load_cert(path) is None:
        ensure_certificates(cert_dir)
    return _load_cert(path).public_bytes(serialization.Encoding.DER)

"""Start the server: http on :8000 and https on :8443, in one process.

    .venv\\Scripts\\python -m watch_pc_controller.run

https is what an iPhone needs for the microphone; http stays for this PC and
for downloading the certificate. uvicorn servers each grab Ctrl+C for

import asyncio
import contextlib

import uvicorn

from watch_pc_controller.tls import ensure_certificates

HTTP_PORT = 8000
HTTPS_PORT = 8443


class QuietServer(uvicorn.Server):
    """A uvicorn server that leaves signal handling to another one."""

    @contextlib.contextmanager
    def capture_signals(self):
        yield


async def serve_both(primary, secondary) -> None:
    second = asyncio.create_task(secondary.serve())
    try:
        await primary.serve()
    finally:
        secondary.should_exit = True
    await second


def main() -> None:
    from watch_pc_controller.server import app, get_local_ip

    cert, key = ensure_certificates()
    http = uvicorn.Server(uvicorn.Config(app, host="0.0.0.0", port=HTTP_PORT))
    # The app's lifespan (closing idle Claude conversations) runs once, on the http server.
    https = QuietServer(uvicorn.Config(app, host="0.0.0.0", port=HTTPS_PORT,
                                       ssl_certfile=cert, ssl_keyfile=key, lifespan="off"))
    ip = get_local_ip()
    print(f"  This PC:  http://localhost:{HTTP_PORT}")
    print(f"  iPhone:   https://{ip}:{HTTPS_PORT}   (first install the certificate from http://{ip}:{HTTP_PORT}/cert)")
    asyncio.run(serve_both(http, https))


if __name__ == "__main__":
    main()

 * Voice for the watch pages: hear the user, speak the replies.
 *
 * Listening streams the microphone to the PC (/api/voice/listen), which
 * relays it to ElevenLabs. When the PC says it cannot (no key, no quota, no
 * internet), the browser's own Hebrew recognition takes over. Speaking asks
 * the PC for audio (/api/voice/speak) and plays it, reporting how loud it is
 * so the orb can pulse with it. Nothing here ever sees the ElevenLabs key.
 */
(function (root, factory) {
  const api = factory(root);
  if (typeof module === 'object' && module.exports) module.exports = api;
  else root.PCVoice = api;
})(typeof self !== 'undefined' ? self : globalThis, function (root) {
  'use strict';

  const RATE = 16000;          // what the PC expects: 16 kHz, 16-bit, mono
  const SEND_MS = 100;         // the microphone goes up in pieces about this long

  // ------------------------------------------------------------ pure pieces

  /** Average `input` (sampled at fromRate) down to toRate. */
  function downsample(input, fromRate, toRate = RATE) {
    if (fromRate === toRate) return Float32Array.from(input);
    const ratio = fromRate / toRate;
    const out = new Float32Array(Math.floor(input.length / ratio));
    for (let i = 0; i < out.length; i++) {
      const start = Math.floor(i * ratio);
      const end = Math.min(input.length, Math.floor((i + 1) * ratio));
      let sum = 0;
      for (let j = start; j < end; j++) sum += input[j];
      out[i] = sum / Math.max(1, end - start);
    }
    return out;
  }

  function toPCM16(floats) {
    const out = new Int16Array(floats.length);
    for (let i = 0; i < floats.length; i++) {
      const s = Math.max(-1, Math.min(1, floats[i]));
      out[i] = s < 0 ? s * 0x8000 : s * 0x7fff;
    }
    return out;
  }

  function rms(floats) {
    let sum = 0;
    for (let i = 0; i < floats.length; i++) sum += floats[i] * floats[i];
    return Math.sqrt(sum / Math.max(1, floats.length));
  }

  /**
   * Decides when the user has finished: once speech was heard, 1.5 s of quiet
   * ends it (spec 1.3); if nothing is said within 8 s, it gives up.
   */
  function SilenceGate({ threshold = 0.015, silenceMs = 1500, patienceMs = 8000, maxMs = 60000 } = {}) {
    let heard = false, quietFor = 0, total = 0;
    return {
      push(level, ms) {
        total += ms;
        if (level >= threshold) { heard = true; quietFor = 0; } else quietFor += ms;
        if (total >= maxMs) return 'done';
        if (heard && quietFor >= silenceMs) return 'done';
        if (!heard && total >= patienceMs) return 'nothing';
        return heard ? 'speaking' : 'waiting';
      },
      get heard() { return heard; },
    };
  }

  function token() {
    try { return root.localStorage ? root.localStorage.getItem('pcToken') : null; } catch (e) { return null; }
  }
  function authHeaders(extra) {
    const headers = Object.assign({}, extra || {});
    const t = token();
    if (t) headers.Authorization = 'Bearer ' + t;
    return headers;
  }
  function socketUrl(path) {
    const loc = root.location;
    return (loc.protocol === 'https:' ? 'wss://' : 'ws://') + loc.host + path;
  }

  // ------------------------------------------------------------ what the PC can do

  let serverCanListen = null;         // null: not asked yet
  async function prepare() {
    try {
      const res = await root.fetch('/api/voice/status', { headers: authHeaders() });
      if (res.ok) {
        const status = await res.json();
        serverCanListen = !!status.elevenlabs_configured;
        return status;
      }
    } catch (e) { /* the PC is away: decide when listening */ }
    serverCanListen = null;
    return null;
  }

  // ------------------------------------------------------------ listening

  /** The browser's own recognition, in Hebrew. Same shape as listen(). */
  function browserListen(cb = {}) {
    const Rec = root.SpeechRecognition || root.webkitSpeechRecognition;
    let finish;
    const done = new Promise((resolve) => { finish = resolve; });
    if (!Rec) { finish(''); return { done, stop() {}, cancel() {} }; }
    const rec = new Rec();
    rec.lang = 'he-IL';
    rec.interimResults = true;
    rec.continuous = false;
    let text = '';
    rec.onresult = (e) => {
      let t = '';
      for (let i = 0; i < e.results.length; i++) t += e.results[i][0].transcript;
      text = t;
      if (cb.onPartial) cb.onPartial(t);
    };
    rec.onend = () => finish(text.trim());
    rec.onerror = () => finish(text.trim());
    try { rec.start(); } catch (e) { finish(''); }
    return {
      done,
      stop() { try { rec.stop(); } catch (e) { finish(text.trim()); } },
      cancel() { try { rec.abort(); } catch (e) { /* already gone */ } finish(''); },
    };
  }

  /**
   * Listen once. Callbacks: onPartial(text), onLevel(0..1), onSource(source, reason)
   * where source is 'elevenlabs' or 'browser'. Returns { done: Promise<text>, stop(), cancel() }.
   */
  function listen(cb = {}) {
    let settled = false, finish;
    const done = new Promise((resolve) => {
      finish = (text) => { if (settled) return; settled = true; release(); resolve(text || ''); };
    });
    let ws = null, ready = false, stopped = false, fallback = null;
    let stream = null, ctx = null;
    const finals = [];
    let pending = [], pendingLength = 0;

    const release = () => {
      if (ws) { try { ws.close(); } catch (e) { /* closed */ } ws = null; }
      if (stream) { stream.getTracks().forEach((t) => t.stop()); stream = null; }
      if (ctx) { try { ctx.close(); } catch (e) { /* closed */ } ctx = null; }
    };
    const controller = {
      done,
      stop() {
        if (fallback) return fallback.stop();
        if (stopped) return;
        stopped = true;
        sendPending();
        if (ws && ws.readyState === 1 && ready) ws.send(JSON.stringify({ type: 'stop' }));
        else finish(finals.join(' '));
      },
      cancel() { if (fallback) fallback.cancel(); finish(''); },
    };

    const toBrowser = (reason) => {
      if (settled || fallback) return;
      release();
      if (cb.onSource) cb.onSource('browser', reason);
      fallback = browserListen(cb);
      if (stopped) fallback.stop();
      fallback.done.then((text) => finish(text));
    };

    if (serverCanListen === false) { toBrowser('no_key'); return controller; }   // decide inside the tap (iOS)

    try { ws = new root.WebSocket(socketUrl('/api/voice/listen')); } catch (e) { toBrowser('socket'); return controller; }
    ws.binaryType = 'arraybuffer';
    ws.onopen = () => { const t = token(); if (t) ws.send(JSON.stringify({ type: 'auth', token: t })); };
    ws.onerror = () => { if (!ready) toBrowser('socket'); };
    ws.onclose = () => { if (!ready) toBrowser('socket'); else finish(finals.join(' ')); };
    ws.onmessage = (e) => {
      let msg;
      try { msg = JSON.parse(e.data); } catch (err) { return; }
      if (msg.type === 'unavailable') { toBrowser(msg.reason); return; }
      if (msg.type === 'ready') {
        ready = true;
        if (cb.onSource) cb.onSource('elevenlabs', '');
        startMicrophone().catch(() => finish(''));
        return;
      }
      if (msg.type === 'partial' && cb.onPartial) cb.onPartial(finals.concat(msg.text ? [msg.text] : []).join(' '));
      if (msg.type === 'final') { if (msg.text) finals.push(msg.text); if (cb.onPartial) cb.onPartial(finals.join(' ')); }
      if (msg.type === 'done') finish(msg.text);
      if (msg.type === 'error') { if (cb.onError) cb.onError(msg.reason); finish(finals.join(' ')); }
    };

    function sendPending() {
      if (!pendingLength || !ws || ws.readyState !== 1 || !ctx) { pending = []; pendingLength = 0; return; }
      const merged = new Float32Array(pendingLength);
      let at = 0;
      for (const piece of pending) { merged.set(piece, at); at += piece.length; }
      pending = []; pendingLength = 0;
      ws.send(toPCM16(downsample(merged, ctx.sampleRate)).buffer);
    }

    async function startMicrophone() {
      stream = await root.navigator.mediaDevices.getUserMedia({
        audio: { channelCount: 1, echoCancellation: true, noiseSuppression: true, autoGainControl: true },
      });
      ctx = new (root.AudioContext || root.webkitAudioContext)();
      await ctx.audioWorklet.addModule('/static/pcm-worklet.js');
      if (settled) return;
      const source = ctx.createMediaStreamSource(stream);
      const tap = new root.AudioWorkletNode(ctx, 'pcm-tap');
      const mute = ctx.createGain();
      mute.gain.value = 0;                 // pulled by the speakers so it runs, but never heard
      source.connect(tap); tap.connect(mute); mute.connect(ctx.destination);
      const gate = SilenceGate();
      tap.port.onmessage = (e) => {
        if (stopped || settled) return;
        const block = e.data;
        const level = rms(block);
        if (cb.onLevel) cb.onLevel(Math.min(1, level * 8));
        pending.push(block); pendingLength += block.length;
        if (pendingLength >= ctx.sampleRate * SEND_MS / 1000) sendPending();
        const verdict = gate.push(level, (block.length / ctx.sampleRate) * 1000);
        if (verdict === 'done' || verdict === 'nothing') controller.stop();
      };
    }
    return controller;
  }

  // ------------------------------------------------------------ speaking

  let audioCtx = null;
  let current = null;          // { audio, end }

  /** Call from a tap: iOS lets a page make sound only after a gesture. */
  function unlock() {
    try {
      audioCtx = audioCtx || new (root.AudioContext || root.webkitAudioContext)();
      if (audioCtx.state === 'suspended') audioCtx.resume();
      const silence = audioCtx.createBufferSource();
      silence.buffer = audioCtx.createBuffer(1, 1, 22050);
      silence.connect(audioCtx.destination);
      silence.start(0);
    } catch (e) { /* no Web Audio: speaking still works, without the level meter */ }
  }

  function meter(audio, onLevel) {
    if (!onLevel || !audioCtx) return () => {};
    let raf = 0;
    try {
      const analyser = audioCtx.createAnalyser();
      analyser.fftSize = 512;
      audioCtx.createMediaElementSource(audio).connect(analyser);
      analyser.connect(audioCtx.destination);
      const data = new Float32Array(analyser.fftSize);
      const tick = () => { analyser.getFloatTimeDomainData(data); onLevel(Math.min(1, rms(data) * 5)); raf = root.requestAnimationFrame(tick); };
      tick();
    } catch (e) { return () => {}; }
    return () => root.cancelAnimationFrame(raf);
  }

  function browserSpeak(text, cb) {
    return new Promise((resolve) => {
      const synth = root.speechSynthesis;
      if (!synth) { resolve(); return; }
      const voice = synth.getVoices().find((v) => /^(he|iw)/i.test(v.lang));
      if (!voice) { resolve(); return; }
      const u = new root.SpeechSynthesisUtterance(text);
      u.voice = voice; u.lang = voice.lang;
      u.onend = resolve; u.onerror = resolve;
      synth.speak(u);
      if (cb.onStart) cb.onStart();
    });
  }

  /**
   * Speak `text` in the PC's voice. Callbacks: onVoice(provider, fallbackReason),
   * onStart(), onLevel(0..1). Resolves when the audio ends or is stopped.
   */
  async function speak(text, cb = {}) {
    stopSpeaking();
    let res = null;
    try {
      res = await root.fetch('/api/voice/speak', {
        method: 'POST',
        headers: authHeaders({ 'Content-Type': 'application/json' }),
        body: JSON.stringify({ text }),
      });
    } catch (e) { res = null; }
    if (!res || !res.ok) {
      if (cb.onVoice) cb.onVoice('browser', res ? 'server_' + res.status : 'offline');
      return browserSpeak(text, cb);
    }
    if (cb.onVoice) cb.onVoice(res.headers.get('X-Voice-Provider'), res.headers.get('X-Voice-Fallback') || '');
    const url = root.URL.createObjectURL(await res.blob());
    return new Promise((resolve) => {
      const audio = new root.Audio(url);
      let stopMeter = () => {};
      const end = () => {
        if (current && current.audio === audio) current = null;
        stopMeter();
        root.URL.revokeObjectURL(url);
        resolve();
      };
      current = { audio, end };
      audio.onended = end;
      audio.onerror = end;
      stopMeter = meter(audio, cb.onLevel);
      Promise.resolve(audio.play()).then(() => { if (cb.onStart) cb.onStart(); }).catch(end);
    });
  }

  function stopSpeaking() {
    if (current) { try { current.audio.pause(); } catch (e) { /* gone */ } current.end(); }
    if (root.speechSynthesis) { try { root.speechSynthesis.cancel(); } catch (e) { /* none */ } }
  }

  return {
    prepare, listen, speak, stopSpeaking, unlock,
    _internal: { downsample, toPCM16, rms, SilenceGate, browserListen },
  };
});

"""Check the voice end to end against the running server.

    .venv\\Scripts\\python scripts\\voice_e2e.py

Speaks a Hebrew sentence through /api/voice/speak and reports which voice
answered; then records a short Hebrew sentence with the offline Asaf voice,
streams it to /api/voice/listen as if it were the microphone, and prints
what ElevenLabs heard. Costs about 30 characters of speech and a few seconds
of transcription.
"""

import array
import asyncio
import io
import json
import os
import sys
import wave

import httpx
from websockets.asyncio.client import connect

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from watch_pc_controller.tts import AsafTTS  # noqa: E402

BASE = sys.argv[1] if len(sys.argv) > 1 else "http://127.0.0.1:8000"
SPOKEN = "שלום, זו בדיקה של הקול."
HEARD = "זו בדיקה של זיהוי הדיבור"


def pcm_16k(wav_bytes: bytes) -> bytes:
    """A WAV (any rate, 16-bit) as 16 kHz mono 16-bit PCM, by linear interpolation."""
    with wave.open(io.BytesIO(wav_bytes)) as w:
        rate, width, channels = w.getframerate(), w.getsampwidth(), w.getnchannels()
        frames = w.readframes(w.getnframes())
    if width != 2:
        raise ValueError(f"expected 16-bit audio, got {width * 8}-bit")
    samples = array.array("h", frames)[::channels]
    step = rate / 16000
    out = array.array("h")
    for i in range(int(len(samples) / step)):
        pos = i * step
        j = int(pos)
        a, b = samples[j], samples[min(j + 1, len(samples) - 1)]
        out.append(int(a + (b - a) * (pos - j)))
    return out.tobytes()


async def main() -> int:
    checks = {}
    async with httpx.AsyncClient(base_url=BASE, timeout=60) as http:
        status = (await http.get("/api/voice/status")).json()
        print("status:", json.dumps(status, ensure_ascii=False))
        checks["the ElevenLabs key is set up"] = status["elevenlabs_configured"]
        res = await http.post("/api/voice/speak", json={"text": SPOKEN})
        provider, why = res.headers.get("x-voice-provider"), res.headers.get("x-voice-fallback")
        print(f"speak: {res.status_code}, voice={provider}, fallback={why!r}, {len(res.content)} bytes")
        checks["ElevenLabs speaks Hebrew"] = res.status_code == 200 and provider == "elevenlabs" and len(res.content) > 2000

    recording = b"".join([c async for c in await AsafTTS().open(HEARD, 1.0)])
    pcm = pcm_16k(recording)
    heard = ""
    async with connect(BASE.replace("http", "ws", 1) + "/api/voice/listen") as ws:
        first = json.loads(await ws.recv())
        print("listen:", first)
        if first.get("type") == "ready":
            for i in range(0, len(pcm), 3200):             # 100 ms at a time, at the speed of speech
                await ws.send(pcm[i:i + 3200])
                await asyncio.sleep(0.1)
            await asyncio.sleep(0.5)
            await ws.send(json.dumps({"type": "stop"}))
            async for raw in ws:
                message = json.loads(raw)
                print("  ", json.dumps(message, ensure_ascii=False))
                if message["type"] in ("done", "error"):
                    heard = message.get("text", "")
                    break
    checks["ElevenLabs hears Hebrew"] = "בדיקה" in heard

    for name, ok in checks.items():
        print("OK  " if ok else "FAIL", name)
    return 0 if all(checks.values()) else 1


if __name__ == "__main__":
    sys.exit(asyncio.run(main()))
```
